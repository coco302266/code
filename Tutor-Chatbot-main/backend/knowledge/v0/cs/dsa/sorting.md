# 排序算法

## 一句话结论

排序是数据结构与算法的高频基础。平均来看：快排、归并、堆排是 O(n log n) 的「比较排序三剑客」；插入排序在小规模或部分有序时很快；桶/计数/基数排序在特定数据下能到 O(n)。工程上（如编程语言内置 sort）多用「快排 + 插入 + 归并」的混合。

## 标准答案

**O(n²) 家族（简单但不适合大规模）**

- 冒泡：相邻比较交换，最直观，实际很少用。
- 选择：每轮选最小的放前面，交换次数少但比较次数固定。
- 插入：把当前元素插到前面已排好序的部分，小规模/部分有序时优秀。

**O(n log n) 家族**

- 归并排序：分治，先排两半再合并。稳定，最坏也是 O(n log n)，但需要额外 O(n) 空间。
- 快速排序：选基准 partition，递归排两边。平均 O(n log n)，最坏 O(n²)（已有序且选端点做基准时），工程上用「随机基准 + 三数取中 + 小数组切插入」规避。
- 堆排序：建堆后反复取堆顶。O(n log n)、原地、最坏也稳定 O(n log n)，但不稳定且缓存局部性差。

**线性时间排序（有前提）**

- 计数排序：数据范围不大时，数每个值出现几次再展开。
- 桶排序：分到若干桶各自排。
- 基数排序：按位（个位→高位）依次排。

## 原理展开

**为什么快排快、归并稳**

快排的 partition 把数据原地重排，缓存局部性好、常数小，所以平均最快；但它不稳定（相同元素可能换位）。归并排序合并时是按序取，相同元素先后顺序不变，所以稳定，但要额外数组。

**稳定性是什么、为什么重要**

稳定 = 相等元素排序后相对顺序不变。多关键字排序时重要：先按成绩排、再按姓名稳定排，才能得到「同名次内按姓名有序」。如果不稳定，第一遍的成绩顺序会被打乱。

**工程里的 introsort**

C++ 的 `std::sort` 用的是 introsort：小规模用插入排序，规模大用快排，一旦递归深度超过阈值就切到堆排序，从而兼得快排的平均速度和堆排的最坏保证。

## 面试常问

1. 快排为什么平均 O(n log n)？每轮 partition 把数组大致分成两半，递归深度 log n，每层总共扫 n 个元素。
2. 哪些排序是稳定的？冒泡、插入、归并、计数/桶/基数稳定；选择、快排、堆排不稳定。
3. 几乎有序的数组用什么排最快？插入排序（O(n)），或 Timsort（Python/list.sort 用的，对部分有序极好）。
